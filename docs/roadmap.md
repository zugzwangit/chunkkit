# Roadmap

## 0.1 — foundation

Canonical schemas, deterministic chunkers, plugin SDK, local connector, context packing, offline
evaluation, CLI, service demo, and enterprise connector bases.

## 0.2 — integration depth

Golden vendor fixtures, attachment expansion, provider token-counting adapters, pgvector production
adapter, robust REST throttling, and connector-specific ACL resolvers.

## 0.3 — research strategies

Semantic breakpoints, Tree-sitter language packs, parent-child graphs, late chunking, proposition
extraction, parameter search, and richer statistical reports.

## 1.0 — stable ecosystem

Stable schemas/plugin API, audited tenant and ACL enforcement, production deployment reference,
compatibility suite, and community plugin catalog.
