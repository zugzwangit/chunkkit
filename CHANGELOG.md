# Changelog

All notable changes are documented here. The format follows Keep a Changelog and releases follow
Semantic Versioning.

## [Unreleased]

### Added

- Framework-neutral Pydantic document, chunk, ACL, model, and experiment schemas.
- Deterministic chunking pipeline with synchronous and asynchronous streaming.
- Token, sliding, recursive, sentence, paragraph, Markdown, code, and adaptive chunkers.
- Plugin discovery and standalone plugin scaffolding.
- Local parsers, filesystem connector, enterprise REST connector adapters, SQLite state, local
  artifacts, deterministic embeddings, exact retrieval, context packing, and offline evaluation.
- JSONL and optional LangChain, LlamaIndex, Haystack, Qdrant, and Pinecone adapters.
- Dependency-free CLI and optional authenticated FastAPI service.
